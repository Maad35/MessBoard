Mulai dalam 5 menit

MessBoard memakai alur board-first: tentukan file board dulu, masukkan referensi, lalu susun semuanya langsung di kanvas.

Recent boards: 3 board terakhir muncul di layar awal dan di menu Board → Open recent… — klik untuk langsung membuka tanpa mencari folder.

Buka MessBoardDi After Effects: Window → Extensions → MessBoard.
Buat board baruPilih New board…, tentukan nama dan lokasi file .messboard.
Masukkan materiKlik Add, drag gambar dari file manager, atau paste gambar, teks, dan URL dengan Ctrl + V.
Susun boardDrag objek, resize, rotate, group, dan pakai Arrange (A). Scroll untuk zoom, Space + drag untuk pan.
SimpanCtrl + S untuk save, Ctrl + Shift + S untuk Save As.
Gambar lokal tetap terhubung ke file sumbernya. MessBoard tidak mengompresi atau mengubah file aslimu.

Kanvas & navigasi

Pan

Tahan Space sambil drag, atau pakai tombol tengah mouse.

Zoom

Scroll di kanvas. Zoom mengikuti posisi pointer — area yang sedang kamu lihat tetap jadi titik acuan.

Focus & Fit

F untuk fokus ke seleksi. Shift + F untuk tampilkan seluruh board.

Grid

Pilih dots, lines, atau none di Canvas settings. Atur ukuran, warna, dan opacity. Grid mengikuti kanvas saat kamera bergerak.

Status save tetap tenang. Hanya perubahan objek atau pengaturan yang menandai "Unsaved". Sekadar pan/zoom tidak mengubah status.

Menambah referensi

Gambar lokal

  • Klik Add untuk pilih beberapa gambar sekaligus.
  • Drag-and-drop gambar langsung ke kanvas.
  • Paste screenshot atau gambar dari clipboard (Ctrl + V).
  • Auto-arrange: menambah 2+ file sekaligus (via Add atau drag-and-drop) otomatis tersusun rapi dalam grid.

Extract colors

Klik kanan gambar → Extract colors… untuk mengekstrak palet 8 warna dominan dari gambar. Klik warna mana saja untuk menyalin kode hex-nya. Tombol Place on board menaruh palet sebagai gambar di board — berguna sebagai referensi warna dan bisa di-Send ke AE.

Gambar dari web

Paste URL gambar langsung — MessBoard akan mengunduhnya. Paste URL YouTube untuk membuat kartu video, URL web biasa jadi catatan teks.

Thumbnail otomatis. Untuk board berisi banyak gambar besar, MessBoard membuat thumbnail ringan agar pan/zoom tetap mulus. Thumbnail dibuat otomatis dan disimpan di folder thumbs. Gambar asli selalu dipakai untuk Send ke AE dan export.

Video & YouTube

Kartu video punya dua mode: thumbnail ringan untuk disusun, dan player penuh saat diputar.

Video lokal

Format yang didukung: MP4 (H.264), WebM. Klik Play untuk memutar langsung di board. Bar kontrol player menyediakan play/pause, mute, scrub, dan tombol fullscreen di ujung kanan untuk menonton satu layar penuh (Esc untuk keluar). Klik videonya atau tombol besar di tengah untuk play/pause cepat ala YouTube. Selama player aktif, kursor di atas video adalah kursor biasa; menekan Stop di titlebar mengembalikannya ke kursor board.

YouTube

Paste link YouTube — judul asli diambil otomatis. Klik Play untuk player, Stop untuk kembali ke thumbnail agar kartu bisa di-drag lagi.

Video "unavailable". Sebagian video YouTube menonaktifkan embedding oleh pemiliknya — video tersebut tetap bisa diputar di youtube.com tapi tidak di player tertanam. Ini pembatasan dari YouTube. Klik Open untuk nonton di browser.

Catatan teks

Klik canvas dengan tool Text untuk membuat catatan; tahan Alt saat klik untuk snap titik asal catatan ke tepi atau tengah item lain. Double-click catatan untuk mengedit. Catatan tumbuh otomatis mengikuti isi teks.

Format teks

  • Font, ukuran, bold, italic, underline.
  • Klik di luar daftar font menutup daftar tanpa mengubah font catatan.
  • Perataan horizontal & vertikal, line height, letter spacing.
  • Bulleted list dan numbered list.
  • Teks horizontal atau vertikal (tategaki).

Seleksi teks tanpa edit mode

Tahan Ctrl lalu drag di atas teks untuk highlight, tanpa perlu double-click masuk mode editing. Selama Ctrl ditahan di atas teks catatan, kursor berubah menjadi kursor teks sebagai penanda. Drag biasa di mana pun pada catatan memindahkannya, sama seperti item lain. Teks yang di-highlight bisa langsung dikirim ke After Effects (lihat Workflow AE).

Kotak catatan

Atur warna teks, background, padding, corner radius, dan opacity. Semua perubahan mendukung Undo.

Drawing & shape

Draw P

Gambar bebas dengan pen. Atur warna, ketebalan, dan opacity di panel drawing. Slider Smoothing di panel menstabilkan goresan dari getaran tangan: nilai lebih tinggi memberi garis yang lebih halus tetapi lebih mengikuti di belakang kursor, dan 0 mematikannya sama sekali.

Shape U

Persegi, lingkaran, garis, dan panah. Shift untuk proporsi sempurna (kotak jadi persegi, dll). Alt untuk snap titik akhir ke tepi atau tengah item lain.

Erase

Hapus seluruh drawing/shape. Gambar dan catatan tidak tersentuh.

Seleksi & transform

Select

Klik untuk seleksi tunggal. Drag area kosong untuk marquee. Tahan kotak marquee di tepi panel untuk menggeser tampilan (edge pan) dan memperluas seleksi melampaui area yang terlihat; kecepatannya diatur di Preferences. Ctrl + klik untuk toggle. Ctrl + A untuk semua. Kursor di atas item yang belum terseleksi adalah panah biasa; kursor berubah menjadi move hanya di atas item yang sedang terseleksi, dan bertahan sebagai move selama drag memindahkan berlangsung.

Move

Drag seleksi; tahan di tepi panel untuk edge pan bila tujuan berada di luar tampilan. Tahan Ctrl untuk snap ke grid, Alt untuk snap ke objek terdekat.

Resize

Pakai delapan handle di sekeliling seleksi. Kursor rotate mengikuti rotasi item, jadi arah panahnya selalu searah dengan sudut yang sedang ditarik. Item video (file video dan YouTube) selalu mengunci aspek rasio agar tidak gepeng. Gambar bebas diubah per sisinya. Shift mengunci aspek rasio untuk item apa pun, Ctrl mengaktifkan snap ukuran, Alt menempelkan tepi yang ditarik ke tepi atau tengah item lain.

Rotate

Hover di dekat sudut selection box hingga kursor panah melengkung muncul, lalu drag. Ctrl snap 10°, Shift snap 45°.

Crop C

Pilih satu gambar, tekan C atau klik Crop. Atur frame, Enter untuk terapkan, Esc untuk batal. Non-destruktif — file asli tidak diubah.

Arrange & group

Pilih minimal dua objek, tekan A untuk buka panel Arrange.

Align & Distribute

Align menyamakan posisi tepi (kiri, tengah, kanan, atas, tengah vertikal, bawah). Distribute meratakan jarak antar objek — butuh minimal tiga objek; yang paling ujung diam, yang tengah digeser sampai spasinya sama.

Size

Samakan lebar, tinggi, atau keduanya. Atau normalisasi ke area terbesar/terkecil dengan proporsi tetap.

Layout

Grid

Kisi-kisi rapi dengan sel seragam. Cocok untuk item berukuran mirip.

Pack

Disusun sepadat mungkin untuk menghemat ruang. Cocok untuk item berukuran acak.

Stack H / Stack V

Satu baris horizontal atau satu kolom vertikal, otomatis rata tengah di sumbu tegak lurusnya. Cocok untuk sequence atau perbandingan.

Gap

Slider 0–100px untuk atur jarak antar item. Berlaku untuk Grid, Pack, dan Stack.

Group

Group bergerak sebagai satu unit. Double-click anggota atau pilih Edit group contents untuk masuk. Tidak mendukung nested group.

Sections

Section adalah frame bernama untuk membagi board menjadi wilayah-wilayah, misalnya per tema referensi (Karakter, Latar, Palet Warna) atau per tahap pengerjaan. Klik Section di toolbar lalu drag di canvas untuk menggambar framenya (tahan Shift untuk mengunci proporsi 1:1, tahan Alt untuk snap sudut ke tepi atau tengah item lain); drag yang terlalu kecil diganti frame ukuran default di titik klik. Beri nama langsung setelah membuat, atau double-click labelnya kapan saja untuk rename.

Keanggotaan section bersifat spasial: item apa pun yang titik tengahnya berada di dalam frame dianggap isinya. Seret label section untuk memindahkan frame beserta seluruh isinya sekaligus. Item di dalamnya tetap individual, bisa diseleksi, dipindah keluar masuk frame, dan dikirim ke AE seperti biasa. Menghapus section hanya menghapus framenya, isinya tetap di board. Beda dengan Group: group mengikat item jadi satu unit, sedangkan section adalah wilayah visual, jadi keduanya bisa dipakai bersamaan.

Seleksi sebuah section lalu buka Properties untuk mengaturnya: nama, warna tint custom lewat color picker (atau ikuti warna aksen board lewat tombol Theme), berguna sebagai kode warna per bagian, intensitas tint, ketebalan dan gaya garis frame (solid/dashed), radius sudut, ukuran label (S/M/L, dan ukuran label, garis, serta radius selalu menyesuaikan besar section), posisi label dengan pemilih titik anchor 3×3 (sembilan posisi, di dalam atau di luar frame), tampil/sembunyi label, dan tombol Arrange contents (rapikan isi ke grid di dalam frame) serta Fit frame to contents (frame menyusut pas mengitari isinya). Matikan Contents follow when dragging bila frame perlu digeser tanpa membawa isinya. Gaya terakhir yang dipakai tersimpan dan menjadi gaya awal untuk section berikutnya.

Properties

Tekan E atau klik Properties untuk panel konteks sesuai seleksi: opacity objek, flip horizontal/vertikal gambar, crop, relink, dan pengaturan spesifik tiap tipe.

Tampilan board

Canvas settings

Background, gaya grid (dots/lines/none), warna & ukuran grid, opacity grid, warna aksen, warna panel, warna teks, dan auto-hide toolbar. Warna panel dan teks menema seluruh panel dan menu board ini; nuansa turunannya (latar aplikasi, kontrol, hover, garis, teks redup) dihitung otomatis. Tersimpan bersama board dan mendukung Undo.

Image thumbnails

Thumbnail ringan dibuat otomatis untuk gambar besar agar navigasi tetap mulus. Pengaturan: aktif/nonaktif, ukuran (512/1024/2048px), dan batas zoom untuk tukar ke resolusi penuh. GIF dilewati agar animasi tetap berjalan. Khusus panel Items, baris GIF memakai pratinjau mini berupa satu frame diam supaya daftarnya tidak ikut bergerak; di board sendiri GIF tetap beranimasi.

Color picker

Mendukung HSB, RGB, HEX, preview, dan eyedropper layar. OK/Enter terapkan, Cancel/Esc kembalikan.

Preferences

MessBoard → Preferences… menyimpan pengaturan instalasi ini (tidak ikut file board): label toolbar, kecepatan edge-pan, dan default untuk board baru.

Toolbar

Toolbar dikelompokkan berdasarkan fungsi. Saat jendela sempit, grup berprioritas rendah otomatis masuk ke menu More.

Create

Add, Text, Draw, Shape, Erase, Section — membuat objek baru.

Modify

Arrange, Properties, Crop — mengatur objek yang diseleksi.

History

Undo (Ctrl+Z), Redo (Ctrl+Shift+Z) — selalu terlihat.

Board

Send — kirim ke After Effects (I). Replace — ganti konten/source layer AE terpilih (Shift+I). Fit — tampilkan seluruh board (Shift+F). Items — daftar semua objek.

Mode label

Di Preferences pilih Labels (teks di samping ikon) atau Icons (ikon saja, lebih ringkas untuk jendela sempit).

Workflow After Effects

Jembatan dua arah antara board dan composition.

Send I

Kirim gambar, video lokal, dan catatan yang diseleksi ke composition aktif. Posisi, skala, rotasi, opacity, dan crop mask diterjemahkan ke layer AE.

Smart placement: jika ada layer terseleksi di AE, layer baru muncul tepat di atasnya dengan durasi (in/out point) yang sama. Jika tidak ada, layer dibuat di paling atas dengan durasi default.

Catatan → text layer

Catatan dikirim sebagai text layer native (bukan gambar). Font dan ukuran mengikuti default After Effects.

Seleksi teks: Ctrl+drag untuk highlight sebagian teks catatan sebelum Send, hanya bagian itu yang dikirim.

Replace Shift+I

Seperti Alt+drag dari Project panel — mengganti source tanpa mengubah sisanya.

Text: jika ada text layer terseleksi di AE, isinya digantikan teks dari catatan (formatting tetap). Satu catatan mengganti semua text layer yang terseleksi.

Image/Video: jika ada footage layer terseleksi di AE, source-nya digantikan gambar/video dari board (posisi, efek, keyframe tetap). Satu asset mengganti semua layer yang terseleksi; banyak asset dipasangkan satu-satu mengikuti urutan.

Cocok untuk alur berbasis template: susun satu versi sampai selesai, lalu ganti asetnya untuk membuat versi berikutnya.

Capture frame

Ambil still dari composition aktif: full comp, layer terpilih, atau work area. Hasilnya jadi kartu gambar di board.

Project link

Hubungkan board ke file AEP tertentu agar tidak salah kirim ke project lain.

Sebelum Capture/Send. Pastikan ada composition aktif. Untuk import teks pertama kali mungkin terasa lambat (AE menginisialisasi text engine) — selanjutnya instan.

File & export

Collect

Salin gambar lokal ke folder pendamping board dan perbarui link-nya. File asli tidak diubah.

Board dari seleksi

Buat file .messboard baru dari seleksi beserta asetnya, tanpa mengganti board aktif.

Portable ZIP

Kemas board + gambar lokal jadi satu ZIP. Extract seluruhnya sebelum dibuka. Media online tetap berupa URL.

Export PNG

Export board atau seleksi pada 0.5×, 1×, atau 2×. Background bisa transparan. Grid tidak ikut.

Gambar hilang

Pakai Check again, Search folder (mencari rekursif berdasarkan nama file), atau Relink manual.

Board portable. Pindahkan Board.messboard bersama folder Board_files — jangan rename salah satunya saja.
Soal GIF. GIF diputar otomatis di board, tapi export PNG dan Send ke AE hanya membawa satu frame. Untuk animasi penuh, import GIF langsung di After Effects.

Save & recovery

  • Saved — board sama dengan file utama.
  • Unsaved — objek atau pengaturan berubah. Pan/zoom tidak termasuk.
  • Autosave — backup perlindungan, bukan pengganti Save. File arsip lama otomatis dihapus (maksimal 5 terbaru disimpan).
  • Recover autosave — muat backup tanpa langsung menimpa file utama.
  • Save As — salin board + aset ke nama lain. Nama board yang sudah ada boleh dipakai ulang setelah konfirmasi; isi dan aset board lama di nama itu akan diganti.
Sebelum tutup After Effects. Tetap tekan Ctrl + S. Recovery membantu saat crash, bukan pengganti save eksplisit.

  • File LICENSE di paket distribusi berisi aturan lengkapnya.
Kontribusi. Fork, kembangkan, dan ajukan perubahanmu. Pastikan seluruh pengujian lulus (node --test tests/) sebelum mengajukan.

  • Board tak terbatas: kanvas infinite dengan pan dan zoom bebas untuk menyusun referensi visual dalam satu workspace, plus edge pan saat drag atau marquee ditahan di tepi panel.

Troubleshooting

Video lokal tidak bisa diputar

Codec tidak didukung panel. Konversi ke MP4 (H.264) atau WebM, lalu relink.

Video YouTube "unavailable"

Pemilik video menonaktifkan embedding. Putar lewat tombol Open di browser.

GIF tidak beranimasi saat dikirim ke AE

Normal — Send hanya membawa satu frame. Import GIF langsung di AE untuk animasi penuh.

YouTube tidak merespons drag

Iframe player sedang aktif. Klik Stop untuk kembali ke mode thumbnail.

Gambar jadi missing

File dipindah/dihapus. Pakai Relink atau Search folder.

Capture/Send gagal

Pastikan ada composition aktif, project link benar, dan tidak ada operasi file/crop berjalan.

Import teks pertama lambat (hingga ±30 detik)

Saat teks pertama kali dikirim, After Effects dapat melakukan validasi font secara online. Jika koneksi internet lambat atau terputus, proses ini dapat memakan waktu hingga ±30 detik dan terasa seperti berhenti. Solusi: atur font default di panel Character ke font yang terpasang lokal (misalnya Arial), atau pastikan koneksi ke server Adobe tidak terhalang firewall/VPN.

Board ZIP tidak bisa dibuka

Extract seluruh ZIP dulu, lalu buka .messboard dengan folder pendamping di sebelahnya.

MessBoard tidak muncul di AE

Pastikan terinstal dengan struktur benar, buka via Window → Extensions. Jangan memasang dua versi dengan ID ekstensi yang sama secara bersamaan.

Lapor masalah

Sertakan versi AE, Windows, langkah reproduksi, pesan error, dan screenshot.
